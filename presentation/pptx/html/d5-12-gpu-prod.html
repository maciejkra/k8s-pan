GPU production practices

  • Dedicated node pool — taint nvidia.com/gpu=true:NoSchedule
  • Spot instances — 70-90% taniej (jeśli checkpointing)
  • Karpenter zamiast Cluster Autoscaler — szybszy provisioning, multi-instance type, spot fallback
  • Image pre-loading (Spegel) — 5GB pull × 100 nodów = 500GB ruchu
  • Cost monitoring — OpenCost / Kubecost (per team chargeback)
  • Time-slicing dla dev/inference, MIG dla produkcji

Kluczowa decyzja: on-demand vs spot vs reserved? Karpenter automatyzuje ratowanie z spot termination → on-demand fallback.
