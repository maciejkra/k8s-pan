kube-prometheus-stack

Wszystko w jednym Helm chart: Prometheus Operator + Grafana + AlertManager + node-exporter + kube-state-metrics

Prometheus Operator

  • CRD-y: ServiceMonitor
  • PrometheusRule
  • AlertmanagerConfig
  • PodMonitor, Probe

Grafana

  • Preinstall'd dashboards
  • K8s cluster, node, pod
  • 17813 Trivy reports
  • 12239 DCGM (GPU)

Loki (logs)

  • Promtail / Fluent Bit
  • LogQL (jak PromQL)
  • Chunks compression
  • Cheap object storage (S3)

$ helm install monitoring prometheus-community/kube-prometheus-stack -n monitoring

$ helm install loki grafana/loki-stack -n loki
