Node maintenance — drain + PDB

cordon → drain → patch / reboot → uncordon

$ kubectl cordon $NODE # nie planuj nowych

$ kubectl drain $NODE \

--ignore-daemonsets \ # DaemonSet zostaje

--delete-emptydir-data # temp data

# patch / reboot / replace

$ kubectl uncordon $NODE

apiVersion: policy/v1

kind: PodDisruptionBudget

spec:

minAvailable: "75%" # lub maxUnavailable: 1

selector: { matchLabels: { app: critical } }

drain respektuje PDB — czeka aż ewikcja nie naruszy budżetu. Zero downtime przy patchowaniu floty.
