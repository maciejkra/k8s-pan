ConfigMap — env vars vs mount

Env vars (statyczne)

Zmiana CM → wymaga restart Pod

Aplikacja odczytuje raz przy starcie

Proste dla starych aplikacji

Mount jako pliki (auto)

Auto-refresh ~60s

Aplikacja musi reagować (inotify)

Lepsze dla cloud-native

$ kubectl create configmap conf --from-file=./

$ kubectl create configmap conf --from-env-file=env

$ kubectl create configmap conf --from-literal=KEY=val
