DaemonSet — jeden Pod per node

Zawsze jeden Pod na każdym pasującym node — nowy node → automatyczny Pod.

Use cases

  • Log collector — Fluent Bit, Promtail
  • Metrics — node-exporter, DCGM
  • CNI — Calico, Cilium
  • Security — Falco (D4/08)
  • Storage — Longhorn, Ceph

Filtrowanie nodów

  • nodeSelector — label match
  • affinity — bardziej elastyczne
  • tolerations — taintowane nody (np. CP)

nodeSelector:

nvidia.com/gpu.present: "true"
