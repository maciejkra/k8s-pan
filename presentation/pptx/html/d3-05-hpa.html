HPA — Horizontal Pod Autoscaler

apiVersion: autoscaling/v2

kind: HorizontalPodAutoscaler

spec:

scaleTargetRef: { name: my-app }

minReplicas: 2

maxReplicas: 50

metrics:

    type: Resource

resource: { name: cpu, target: { averageUtilization: 70 } }

  • Wymóg: metrics-server (D3/03)
  • Scale-up szybki, scale-down wolny (default 5 min stabilization)
  • Custom metrics przez Prometheus Adapter (RPS, queue length)
  • VPA = vertical (zmienia requests/limits) · Karpenter = nody (D5/04)
