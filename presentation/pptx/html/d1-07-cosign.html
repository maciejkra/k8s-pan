Supply chain — Cosign + SBOM

  • Cosign (Sigstore) — kryptograficzne podpisywanie obrazów
  • Keyless signing (OIDC) — krótko żyjące cert od GitHub Actions / Google
  • SBOM = Software Bill of Materials — lista WSZYSTKICH komponentów (CycloneDX)
  • Rekor — publiczny transparency log (jak CT dla TLS)

$ cosign sign --key cosign.key myapp:v1

$ trivy image -f cyclonedx -o sbom.json myapp:v1

$ cosign attest --predicate sbom.json --type cyclonedx myapp:v1

$ cosign verify --key cosign.pub myapp:v1 → ✓ valid
