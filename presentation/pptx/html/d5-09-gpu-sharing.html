GPU sharing — 3 modele

W produkcji jedno GPU może być współdzielone między wieloma workloadami. Trzy mechanizmy:

1. Time-slicing

Software multiplexing

1 fizyczne GPU = N wirtualnych

1/N czasu kompute

Wspólna pamięć (walka)

działa wszędzie

brak izolacji

2. MIG (hardware)

Hardware partitioning

Tylko A100 / A30 / H100

Dedicated SMs + memory

1g.5gb, 3g.20gb, 7g.80gb

izolacja, predictable

tylko Ampere/Hopper

3. MPS (NVIDIA)

Multi-Process Service

CUDA processes share context

Mniej overhead niż time-slicing

Wymaga MPS daemon na node

CUDA-optimized

CUDA only
