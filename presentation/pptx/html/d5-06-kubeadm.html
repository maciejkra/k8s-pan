kubeadm — produkcyjny klaster od zera

Cel: 3 CP + 3 worker + kube-vip (HA) + Cilium CNI — 6 VM, ~30 min instalacji.

# Pierwszy CP:

$ sudo kubeadm init --config kubeadm-config.yaml --upload-certs

$ cilium install --version 1.17.6

# Reszta CP:

$ sudo kubeadm join ... --control-plane --certificate-key XYZ

# Workery:

$ sudo kubeadm join ...
