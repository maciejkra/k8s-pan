OPA / Gatekeeper — policy as code

Admission webhook + Rego policy. Wymusza policies w runtime — nie ufa dyscyplinie devów.

# 1. ConstraintTemplate (klasa policy → generuje nowy CRD)

kind: ConstraintTemplate

spec: { crd: { spec: { names: { kind: K8sRequiredLabels } } } }

  targets: [{ rego: "violation[...] { missing = required - provided; ... }" }]

 

# 2. Constraint (instancja — Pod musi mieć label 'owner')

kind: K8sRequiredLabels

spec:

match: { kinds: [{ apiGroups: [""], kinds: [Pod] }] }

parameters: { labels: ["owner"] }

Alternatywa Kyverno — YAML zamiast Rego, prostsze. Native dla K8s, popularniejsze w nowych klastrach.
