Helm — package manager K8s

  • Chart = paczka + templates Go + values.yaml
  • Release = instancja chartu w klastrze (z imieniem)
  • artifacthub.io = "npm dla Helm" (tysiące community charts)

$ helm repo add bitnami https://charts.bitnami.com/bitnami

$ helm install my-app bitnami/wordpress -f values.yaml

$ helm upgrade --install --atomic my-app ./mychart # auto-rollback

$ helm rollback my-app 1

$ helm history my-app

$ helm template ./mychart --debug # render bez install

--atomic w CI: krytyczne — automatic rollback przy fail. Stan release w Secret sh.helm.release.v1.*
