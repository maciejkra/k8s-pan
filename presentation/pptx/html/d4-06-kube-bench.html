kube-bench — CIS K8s Benchmark

~150 best practices security dla klastra K8s, automatyzowane jako Job.

$ kubectl apply -f kube-bench-job.yaml

$ kubectl logs job/kube-bench

[PASS] 1.1.1 API server pod spec permissions 600 ...

[FAIL] 5.1.5 default ServiceAccounts not actively used

[WARN] 5.1.6 Service Account Tokens only mounted where necessary

# Summary: 54 PASS, 12 FAIL, 22 WARN

  • Sekcja 1-3: Control Plane (apiserver, etcd, scheduler, controller-manager)
  • Sekcja 4: Worker Nodes (kubelet, config files)
  • Sekcja 5: Policies (RBAC, PSA, NetworkPolicy)
  • Profile per provider: EKS, GKE, AKS, RKE2 (osobne benchmarki)
